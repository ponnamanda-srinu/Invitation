# వివాహ ఆహ్వాన వెబ్‌సైట్

శ్రీనివాస్ & పద్మావతి వివాహ ఆహ్వానం. `index.html`, ఆహ్వాన చిత్రం (`invitation-card.png`), సంగీతం (`wedding-song.wav`)లను కలిపి ఉంచండి; ప్రత్యేక ప్యాకేజీలు లేదా చెల్లింపు సేవలు అవసరం లేదు.

## ఉపయోగించడం

1. ఈ ఫోల్డర్‌లోని `index.html`ను బ్రౌజర్‌లో తెరవండి. ఇంటర్నెట్ లేకుండానూ పేజీ పనిచేస్తుంది.
2. Androidలో ఫైల్‌ను Acodeలో తెరిచి Preview నొక్కవచ్చు.
3. ఉచితంగా వెబ్‌సైట్‌గా పబ్లిష్ చేయడానికి:
   - `index.html`, `invitation-card.png`, `wedding-song.wav` ఫైళ్లను GitHub repositoryలో upload/push చేయండి.
   - Repositoryలో **Settings → Pages** తెరవండి.
   - **Build and deployment** కింద **Deploy from a branch** ఎంచుకోండి.
   - Branchగా `main`, folderగా `/(root)` ఎంచుకుని **Save** నొక్కండి.
   - కొన్ని నిమిషాల తర్వాత `https://ponnamanda-srinu.github.io/Invitation/`లో తెరవండి. ఉచిత public website కోసం repositoryను Publicగా ఉంచాలి.

## మీ వివరాలు మార్చడం

`index.html` చివర ఉన్న స్క్రిప్ట్‌లో ఈ విలువలను మార్చండి:

- `VENUE_NAME`, `VENUE_ADDRESS`: పెళ్లి వేదిక పేరు, చిరునామా.
- `VENUE_MAPS_URL`: Google Mapsలో వేదికకు సంబంధించిన Share link.
- `RSVP_PHONE`: దేశ కోడ్‌తో WhatsApp నంబర్, `+918096089892` లేదా ఖాళీలు లేకుండా (ఉదా. `+918096089892`). ప్రస్తుతం ఇచ్చిన నంబర్‌ను `91` కోడ్‌తో పెట్టాను. ఖాళీగా ఉంచితే ఆహ్వానాన్ని పంచుకునే WhatsApp లింక్ తెరుచుకుంటుంది.
- `WEDDING_DATE`: తేదీని `YYYY-MM-DDT00:00:00+05:30` ఆకృతిలో మార్చండి.

ప్రస్తుతం 26 ఏప్రిల్ 2027కు కౌంట్‌డౌన్ చూపిస్తుంది. వివాహ తేదీ గడిచిన తర్వాత టైమర్ ఆ రోజు నుంచి గడిచిన సమయాన్ని చూపిస్తుంది. ప్రచురించిన తర్వాత `https://ponnamanda-srinu.github.io/Invitation/` లింక్‌ను WhatsAppలో పంపితే పేజీ ప్రివ్యూలో ఆహ్వాన చిత్రం కనిపిస్తుంది; పేజీ తెరిచినప్పుడు పాట ప్లే అవుతుంది. పాట ఆటోమేటిక్‌గా మొదలవడానికి సందర్శకుడు ఆహ్వానాన్ని తెరవాలి. పబ్లిక్ వెబ్‌సైట్‌లో WhatsApp నంబర్ అందరికీ కనిపిస్తుంది.
